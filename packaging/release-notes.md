## Bolh Place 0.3 — быстрый холст, панель инструментов, оформленный текст

**Отзывчивее.** Карточка меняет размер сразу за мышью, холст с тысячами
карточек двигается плавно. Сохранение и проверка файлов из облака больше
не подтормаживают окно. Сетка притягивает край карточки, только когда он
рядом с линией, — вдали карточка идёт точно за мышью.

**Панель инструментов** слева на холсте:

- выделение (V) и рука для сдвига поля (H);
- карточка (C): щёлкните по полю — там появится карточка;
- список дел (L): карточка сразу с пустым пунктом чек-листа;
- внизу — кнопки «Отменить» и «Повторить».

**Оформленный текст в карточках:**

- жирный, курсив, подчёркнутый, зачёркнутый;
- заголовок, маркированный и нумерованный списки, чек-лист;
- над карточкой во время правки — панель оформления;
- быстрый набор в начале строки: «- », «1. », «[] », «# »;
- Tab и Shift+Tab вкладывают пункты списка;
- галочку можно поставить щелчком по квадрату, не входя в правку;
- двойной щелчок ставит курсор туда, куда щёлкнули.

Исправлено: копия холста после одновременной правки на двух компьютерах
получала тот же id, что и оригинал; Shift+1 во время печати вместо «!»
показывал весь холст; щелчок по кнопкам холста снимал выделение.

Холсты сохраняются в новой версии формата. Программа 0.2 откроет их
только для чтения — обновитесь на всех компьютерах. Программа 0.2.1 сама
предложит обновиться.
