# Лицензии библиотек

Правило проекта — только MIT, Apache, BSD, ISC. Проверка
`scripts/check-licenses.py` идёт в CI на каждую правку и падает, если
появится библиотека с другой лицензией.

## Исключения — нужно решение владельца

GPUI и gpui-component, на которых построен интерфейс (раздел 2
спецификации), сами используют несколько библиотек со свободными, но
другими лицензиями. Без них GPUI не собирается, заменить их нельзя.

| Лицензия | Что это | Зачем |
|---|---|---|
| Unicode-3.0 | таблицы Юникода (icu_*, unicode-ident) | без них нет текста |
| Zlib | foldhash, slotmap, zlib-rs | внутри GPUI |
| CC0-1.0 | notify | слежение за файлами в gpui-component |
| MPL-2.0 | option-ext | через dirs: где лежат папки Windows |
| BSL-1.0 | ryu | быстрые числа в JSON |
| Unlicense | aho-corasick, memchr и др. | у них есть и MIT |

Все они разрешают свободно использовать и распространять программу, в том
числе бесплатно и с открытым кодом. MPL-2.0 требует открывать только
изменения в файлах самой этой библиотеки — мы её не меняем.

Сейчас эти исключения включены в проверку, чтобы сборка шла. Если
владелец против, варианты — в отчёте этапа 1.
